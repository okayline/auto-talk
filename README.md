# auto-talk

Pick 5 of 8 planet neighbours for a street and watch their day: about 10 meetings, each shown with emote bubbles. How two neighbours get along depends on their personality types. A neighbour who clashed stays in the next day.

Plain HTML and JavaScript, no dependencies. Open `index.html` through any local web server (it loads `sim.js` as a module). Tests: `npm test`.
